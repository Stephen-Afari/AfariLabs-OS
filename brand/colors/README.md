# Brand Colors

Reused as-is from the AfariLabs Brand Kit (`/Reference/AfariLabs_Brand_Kit/colors/`):
- `brand-colors.json` — machine-readable source of truth for automated presentation/asset generation
- `brandcolors.js` — JS export of the same values
- `brandcolors.md` — human-readable reference

These values differ from the palette described inline in the OS specification document (Section 28). **Resolved:** this Brand Kit's own files are the authoritative palette for all AfariLabs asset generation — see `brand/README.md` for the confirmed decision and the superseded specification values.
