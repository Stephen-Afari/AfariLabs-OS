# Logos

Reused from the AfariLabs Brand Kit: `afarilabs_primary_icon.png`, `afarilabs_primary_logo_lockup.png`, `afarilabs_icon_family.png`.

These are supplied PNG artwork with ProjectIQ wordmarks replaced by AfariLabs wordmarks. Per the Brand Kit's own README: for production use, visual lockups that still show legacy wordmarks should be recreated/re-exported with the AfariLabs wordmark rather than mechanically edited — no vector master artwork exists yet.
