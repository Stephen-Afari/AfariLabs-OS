# .claude/

Claude Code configuration for working in AfariLabs-OS: skills, agents, commands, hooks and settings.

**Current status: structure only.** Per `CLAUDE.md` and the specification's phased roadmap, a sophisticated autonomous agent framework, the full AfariLabs Orchestrator, the Control Centre and the AfariLabs MCP are explicitly deferred until a pilot project demonstrates they are genuinely needed. This directory currently holds no skills, agents, commands, hooks or settings — only the structure to add them incrementally as Phase B/C work.

This repository remains usable without Claude Code: nothing outside `.claude/` depends on it.
