# Capabilities

The reusable capability areas AfariLabs delivers through, independent of any single client or project. Organized around the Four Production Studios plus Client Success and Delivery (spec Sections 4 and 11).

Each subdirectory will eventually hold capability-specific skills, standards and reusable assets as they are proven through real project work. Currently structure only — no capability content has been built yet (see `CLAUDE.md` for what is deliberately deferred).

See `core/README.md` for how this differs from `core/standards/` (agreed standard vs. applied capability) — `delivery` and `security` exist in both places deliberately, not as duplicates.
