# Decision Records

Holds architecture and governance decision records (ADR-style) for AfariLabs-OS itself — decisions about the control plane, not individual project decisions (those belong in `knowledge/decisions/` once validated, or in the originating project's own repository).

No decision-record format or entries exist yet. The specification (Phase B) calls for a decision-record format to be established as part of reusable capabilities — this is deferred until that phase.

Related: `knowledge/decisions/`, `core/standards/governance/`.
