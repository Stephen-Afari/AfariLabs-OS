# Constitution

The foundational, rarely-changing principles AfariLabs-OS is built on. These are the principles every standard, skill, agent, command and template must remain consistent with.

See `CONSTITUTION.md` in this directory for the current set of principles, drawn directly from the AfariLabs AI Engineering & Delivery OS v1.1 specification (Strategic Design Principles and Strategic Guardrails).

Changes to the constitution are high-impact and require explicit human approval — they are not routine edits.
