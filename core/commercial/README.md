# Commercial Standards

Holds AfariLabs' agreed standards for the Commercial & Client Operating Plane (spec Section 11): the pipeline from lead generation through qualification, discovery, process assessment, AI/automation opportunity assessment, ROI/feasibility/risk, solution proposal, pricing/estimation/SOW, client onboarding, delivery, acceptance, handover, support/retainer, case study/testimonial, and expansion/upsell.

This is distinct from the reusable *artifacts* used at each pipeline stage, which live in `templates/` (e.g. `templates/discovery/`, `templates/proposal/`, `templates/sow/`). This directory holds the agreed standards and method for how the pipeline itself is run — pricing approach, qualification criteria, estimation method, acceptance criteria conventions — as distinct from `capabilities/client-success/`, which holds the applied client-success capability once proven.

No standards documents exist yet. Per the "build the smallest useful capability first" principle, this should be written once real commercial work (the first qualified opportunity or the Desta Cold Store pilot's own internal "client" framing) exposes a genuine, recurring need — not speculatively in advance.
