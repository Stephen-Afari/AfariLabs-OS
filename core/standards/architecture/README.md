# Architecture Standards

Holds AfariLabs' agreed architectural standards for solutions delivered across the four production studios (Automation, Application, AI, Experience & Growth).

## Standards

- [`03-simplest-viable-architecture.md`](03-simplest-viable-architecture.md) — use the simplest architecture that satisfies the requirements; add complexity only when real work exposes the need.
- [`04-deterministic-workflow-vs-agent-decision.md`](04-deterministic-workflow-vs-agent-decision.md) — prefer deterministic workflows over agents unless dynamic reasoning or context-dependent tool selection is genuinely required.

Further architecture standards should be added once real project work (starting with the Desta Cold Store pilot) exposes a genuine, recurring architectural decision worth standardizing — not speculatively in advance.
