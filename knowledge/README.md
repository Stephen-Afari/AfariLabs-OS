# Knowledge

The AfariLabs learning engine: project outcomes converted into lessons, patterns, standards and improved skills (spec Sections 2 and 17).

Promotion chain: PROJECT → BUILD/DELIVER → PROBLEM OR INSIGHT → LESSON CANDIDATE → PATTERN REVIEW/VALIDATION → PATTERN → SKILL/STANDARD → BETTER FUTURE PROJECT.

Not every observation becomes permanent agency knowledge — promotion into the pattern library requires review and validation. Client-confidential information must not be promoted here without authorization and sanitization (spec Section 17).

This directory is currently empty of entries — it holds structure only until the Desta Cold Store pilot produces the first real lessons and candidate patterns.
